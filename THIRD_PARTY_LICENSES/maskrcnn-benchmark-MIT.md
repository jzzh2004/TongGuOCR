# maskrcnn-benchmark Code License

Applies to the communication utilities retained in
`tongguocr/layout/hdc/utils/comm.py`. These utilities are not used by the
released inference entry point. The upstream initial-release implementation
contains the same communication primitives; the local copy adds `get_rank`
and changes formatting.
